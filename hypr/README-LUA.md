# Hyprland Lua configuration

The active Lua entrypoint is `hyprland.lua`. The legacy `hyprland.conf` and sourced `.conf` files remain beside it as a rollback path during migration.

## Validate

From the dotfiles repository:

```sh
bash custom_script/check-hyprland-lua.sh
```

The script checks every Lua file with `luac -p` and runs Hyprland's authoritative offline loader:

```sh
Hyprland --verify-config -c "$PWD/hypr/hyprland.lua"
```

## Activate

Hyprland chooses its root configuration format when the compositor starts. Log out normally and start a new Hyprland session. Do not use `hyprctl reload` to switch from the existing hyprlang session to Lua.

After login, verify:

```sh
hyprctl configerrors
hyprctl -j monitors
hyprctl -j binds
```

## Roll back

From a TTY or another desktop session:

```sh
mv ~/.config/hypr/hyprland.lua ~/.config/hypr/hyprland.lua.disabled
```

Then start a new Hyprland session. Hyprland will fall back to `hyprland.conf`.

To return to Lua:

```sh
mv ~/.config/hypr/hyprland.lua.disabled ~/.config/hypr/hyprland.lua
bash ~/.dotfiles/custom_script/check-hyprland-lua.sh
```

## Generated and external integrations

- `monitors.lua` is generated by nwg-displays and must not be edited manually.
- `Monitor_Profiles/default.lua` is intentionally only a generic `preferred` fallback; specific high-refresh/high-resolution layouts belong in generated profiles.
- `workspaces.lua` holds the special Gromit workspace rule.
- `wallust/wallust-hyprland.lua` is generated from `~/.config/wallust/templates/colors-hyprland.lua`. The tracked source is `wallust/colors-hyprland.lua.wallust`; keep the installed template identical to it.
- `wallust/wallust-hyprland.toml` contains the tracked Wallust configuration snippet that must be merged into `~/.config/wallust/wallust.toml`.
- Wallust still generates `wallust-hyprland.conf` for Hyprlock and other hyprlang consumers.
- Monitor profile selection copies `Monitor_Profiles/*.lua` into `monitors.lua`.
- `UserConfigs/MonitorRecovery.lua` restores `eDP-1` through the native Lua monitor event when the last active output is removed.
- Monitor-local workspace bindings use the Lua hyprsplit checkout at `~/20_areas/hyprsplit/init.lua`; the obsolete C++ hyprpm plugin is not loaded by the Lua config.

For a read-only check against a running Lua session:

```sh
bash ~/.dotfiles/custom_script/check-hyprland-runtime.sh
```

## Known compatibility adjustment

Hyprland's typed Lua API rejects animation speeds above 100. The legacy `borderangle` speed of 180 is represented as 100. The unused legacy `nice` curve was omitted because its control points exceed the Lua API's supported range.
